# V27.4 — provider-neutral model-in-the-loop benchmark

V27.4 defines the contract between an external model and PromptForge without
adding a model/provider dependency.

Pipeline:

```
ticket
  -> PromptForge context preparation
  -> provider-neutral model_input
  -> external agent
  -> strict prediction parser
  -> PromptForge action guard
  -> evaluation
```

The model adapter only needs:

```python
class AgentAdapter:
    def predict(self, model_input) -> mapping:
        ...
```

A replay adapter is included so predictions generated by any external LLM can
be evaluated from JSONL without changing the benchmark.

The built-in demo replays the naive baseline through the exact same model-loop
path. This proves the interface and produces a directly comparable raw-vs-guarded
measurement before attaching a real LLM.

## Prediction JSONL

One JSON object per line:

```json
{"ticket_id":"T-0001","category":"payments","sla":"urgent","priority":"P0","action":"human_review","requires_human":true,"contradiction_detected":true}
```

Then:

```bash
python benchmarks/model_loop_v27.py
```

A real provider can emit the same JSONL and be evaluated through
`run_replay_benchmark("predictions.jsonl")`.
